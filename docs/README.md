# ShadowOS Core: docs for a person

- What this is: a browser-tab desktop prototype (windows, dock, menu bar, built-in apps, local file state). Pre-1.0.
- Run it: `npm install`, then `npm run dev`. Build with `npm run build`.
- Where it sits: ShadowOS is L2. Its L3 components are ADE, the shell and the window manager; the design system is also tracked as an L3 component. DexFolio and DexScape are hosted, not components.
- Relation to dex.md: dex.md Stage 6b runs the private `shadowos` repo (v0.2.0), not this one.
- Legacy narratives: `docs/legacy/` (pre-dates the layer model; retained, not current).
- Releases: see `RELEASING.md`.
